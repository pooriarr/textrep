# The Grand Calculator of Whimsy - A Scribe's Manual

Greetings, intrepid Math Magician! Welcome to the lair of the Grand Calculator of Whimsy, an enchanted tool for all your numerical divinations.

## Summoning the Oracle

To consult the Calculator of Whimsy, you must first have the ancient tongue of Python (version 3.x) installed upon your scrying device.

1.  Ensure your Python scrolls are in order.
2.  Open your terminal or command-granting interface.
3.  Navigate to the sacred directory where `calculator.py` resides.
4.  Invoke the incantation: `python calculator.py`

Upon success, you shall be greeted by the Arcane Scribe, ready to note your queries:
`Greetings, Math Magician! The Great Calculator of Whimsy awaits your commands. Type 'help' for a mystical guide, or 'vanish' to depart. Let the numbers dance!`
`Arcane Scribe> `

## The Art of Numerical Incantations

Simply type your mathematical expressions and press Enter. The Oracle will reveal the result.
Example: `Arcane Scribe> 3 * (4 + 2) - 7 / 2 ^ 3`
The Oracle divines: 3 * (4 + 2) - 7 / 2 ^ 3 = 17.125 (as foretold by the Oracle)

Supported arcane symbols (operators):
*   `+` : Addition
*   `-` : Subtraction
*   `*` : Multiplication
*   `/` : Division
*   `^` : Exponentiation (e.g., `2^3` is 8)
*   `()`: Parentheses for grouping spells

## Available Spells (Commands)

Type these commands at the `Arcane Scribe>` prompt:

*   `m+ <expression>`: Infuse the result of `<expression>` into the Memory Crystal.
    *   *Example:* `m+ 5*2` will add 10 to the Memory Crystal.
*   `m- <expression>`: Withdraw the essence of `<expression>` from the Memory Crystal.
    *   *Example:* `m- 3+1` will subtract 4 from the Memory Crystal.
*   `mr`: Reveal the Memory Crystal's current enchantment (its stored value).
*   `mc`: Cleanse the Memory Crystal with a mystical breeze (sets it to 0).
*   `scrolls`: Unfurl the Chronicles of Calculations Past (displays your calculation history).
*   `help`: Display the Oracle's Guide from within the calculator.
*   `vanish`: Depart from this realm of calculation.
